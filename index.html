First-time setup (do this once, on your computer)

Paste your fine-grained GitHub token. It will be encrypted in this browser and saved to the repository as vault.json. After that you only type the passphrase, on any device.

STEP: CHOOSE A SHORT PASSPHRASE NOW

This is the only thing you and your wife will type on your phones. Make it easy to type but hard to guess:

  • 4 random words, for example copper-lemon-river-ten (an example only, pick your own), or at least 12 characters
  • Not a name, birthday, address or a password you use elsewhere
  • The encrypted file is public, so strangers can try guesses offline - a longer passphrase is safer
  • Tell your wife the passphrase. There is no way to recover it, only to set up again
